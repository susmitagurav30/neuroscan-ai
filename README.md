# NeuroScan AI

## Brain MRI Tumor Classification System

NeuroScan AI is an educational deep learning project that classifies brain MRI images using a trained ResNet-18 model and provides an interactive Streamlit interface.

### Features
- Upload one or multiple MRI images
- Predict image categories and confidence scores
- View class probability distributions
- Review prediction history
- Download prediction reports

### Technologies
- Python
- PyTorch and TorchVision
- ResNet-18
- Streamlit
- Pandas and Pillow
- Scikit-learn

### Run Locally

1. Install Python.
2. Install the dependencies:

   `pip install -r requirements.txt`

3. Start the application:

   `python -m streamlit run app.py`

### Disclaimer
This is an educational prototype, not a clinically validated diagnostic tool. Predictions must not be used as a substitute for professional medical evaluation.
